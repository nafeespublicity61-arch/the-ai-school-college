# The AI School College – Global Education & Productivity Hub

The AI School College is a responsive, single-page educational portal that brings medical studies, artificial intelligence, software engineering, graphics and video editing, PDF utilities, and world curriculums together in one clean dashboard. It is built with plain HTML, Tailwind CSS (CDN), Font Awesome icons, and vanilla JavaScript, so it needs no installation, build step, or backend to run.

## Features

- **Department Hubs:** Six color-coded cards covering Medical & Health Science, AI, Software Engineering, Graphics & Video, PDF Tools, and Global Educational Boards.
- **Live Search:** Type in the hero search bar and the cards filter instantly. A Clear button resets the view, and a friendly message appears when nothing matches.
- **Login and Sign Up:** Modal forms let visitors register and sign in. Passwords are hashed with SHA-256 and saved in the browser's localStorage. The navbar then shows the user's name and a Logout button.
- **Quick Shortcuts:** A scrollable bar links to ChatGPT, Gemini, Claude, Grok, Canva, iLovePDF, VS Code, and YouTube.
- **Sidebar Navigation:** Links to Photoshop, Illustrator, CorelDRAW, InPage Urdu, PhotoRoom, CapCut, Filmora, and the education boards of Pakistan, India, the UK, the UAE, and the USA.
- **Medical Links:** Mayo Hospital Lahore, Mayo Clinic USA, and the World Health Organization.
- **WhatsApp Support:** A one-click button for instant contact.
- **Responsive Design:** A sticky header and flexible layout that work on phones, tablets, and desktops.

## Getting Started

1. Download or clone this repository.
2. Place your `logo.png` in the same folder as `index.html`.
3. Open `index.html` in any modern browser.
4. Replace the placeholder WhatsApp link with your own number, for example `https://wa.me/923001234567`.

## Important Note

Authentication is a front-end demo only. Accounts are stored per browser and are not shared across devices. For real-world use, connect a secure backend and database.

## Tech Stack

HTML5, Tailwind CSS, Font Awesome 6, JavaScript (ES6), and the Web Crypto API.
